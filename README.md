# 🚀 TechVision AI - Modern Tech Blog Website

A modern, responsive AI and technology blog website featuring the latest news and insights on AI, machine learning, web development, and cutting-edge technology.

## 📋 Features

### ✨ Modern Design
- **Gradient Backgrounds**: Beautiful linear gradients throughout the site
- **Glass Morphism Effects**: Modern frosted glass UI elements
- **Responsive Layout**: Fully mobile-responsive design
- **Professional Typography**: Carefully chosen fonts for readability

### 🎨 UI/UX Enhancements
- **Smooth Animations**: Fade-in, slide-in, and floating animations
- **Hover Effects**: Interactive hover states on all clickable elements
- **Button Animations**: Scale and shadow effects on buttons
- **Card Animations**: Smooth card elevation on hover

- **Smooth Scrolling**: Smooth page navigation with nav links

- **Scroll-to-Top Button**: Fixed button that appears on scroll

## 🎯 Customization Guide

### Change Colors
Edit the CSS variables in `Style.css`:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --accent-color: #f093fb;
    /* ... more variables */
}
```

### Add Blog Posts
Add new blog cards in the `.blog-grid` section with:
```html
<article class="blog-card">
    <div class="blog-image" style="background: linear-gradient(...)"></div>
    <div class="blog-content">
        <!-- Content here -->
    </div>
</article>
```

### Modify Content
Edit the HTML content directly in `Index.html` while preserving the structure and classes.
